Project scope

An academic prototype, not a security product.

PhishGuard implements the FYP Machine Learning-Based Intelligent Phishing and Scam Detection System. It combines URL lexical features with NLP cue counts, compares several classifiers, and exposes a browser form for email, SMS, website URLs, and chat text.

What is included

  • Prototype labelled corpus (see data/DATASET.md)
  • URL features: length, host, IP-in-URL, shorteners, suspicious TLDs, brand impersonation
  • NLP cues: urgency, credentials, money language, obfuscation
  • Logistic Regression, Naive Bayes, Decision Tree, Random Forest, SVM, KNN, XGBoost
  • Explainability via SHAP or model importances
  • Flask interface with Safe / Suspicious / Phishing output

What is not included

  • Live mail-server or SMS-gateway blocking
  • A guarantee against previously unseen campaigns
  • Legal takedown or threat-intel feeds
  • Replacement for browser Safe Browsing or enterprise mail filters
